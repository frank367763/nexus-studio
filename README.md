# Nexus Studio

Учебная аудиостудия для Windows на C# и WPF. Курсовой проект по ООП: хотел связать обычную модель студии — артистов, звукоинженеров и оборудование — с приложением, в котором можно записать и обработать звук.

## Что есть в приложении

- Запись с микрофона и воспроизведение аудиофайлов через NAudio.
- Пауза, перемотка, изменение скорости и обратное воспроизведение.
- Четыре пэда для запуска сэмплов, в том числе своих WAV/MP3.
- Окно аранжировки с тремя дорожками: обрезка, громкость, прослушивание и экспорт микса в WAV.
- Списки артистов и звукоинженеров с сохранением в JSON, архив записей и фильтры.

В этом репозитории собрана версия WPF. Ранее у проекта был также интерфейс на MAUI; общие классы перенесены из него, чтобы Windows-версия собиралась самостоятельно.

## Запуск

Нужны Windows и .NET SDK 10.

```powershell
dotnet restore NexusStudio.slnx
dotnet build NexusStudio.slnx
dotnet run --project src/NexusStudio/NexusStudio.csproj
```

Для записи нужен доступ к микрофону. Пэды по умолчанию используют системные звуки Windows — их можно заменить собственными файлами. Аудиофайлы в репозиторий не включены.

## Как устроен код

`MainWindow` отвечает за студию, архив и управление воспроизведением. `ArrangerWindow` собирает микс из дорожек. В папке [Core](src/NexusStudio/Core) находятся модель студии, сессия записи и аудиодвижок.

В модели используются интерфейсы `IPlayable` и `IRecordable`, наследование сотрудников, события изменения состояния и исключения для ошибок сессии. Работа со звуком вынесена в `AudioEngine`; обработка дорожек — в `DAWTrackProvider`.

## Текущее состояние

Сборка проверена на Windows с .NET SDK 10.0.402. Полной проверки записи и воспроизведения на разных устройствах пока нет. При компиляции остаются предупреждения nullable — это отдельная часть дальнейшей доработки.

Длинные записи обрабатываются в памяти. Изменение скорости также меняет высоту тона. Списки сотрудников сохраняются рядом с приложением, поэтому папка запуска должна быть доступна для записи; записи — в `Документы/NexusStudio`. Это учебное приложение, и перед серьёзной работой со звуком ещё нужны тесты аудиопреобразований и проверка освобождения устройств.

При подготовке репозитория восстановлены отсутствовавшие общие классы, добавлены инструкция сборки и исключения для локальных данных. Пользовательские записи и сохранённые списки сюда не загружались.
